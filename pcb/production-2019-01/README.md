# Production files, 2019-01-05

Gerbers and drill files of the produced AC dimmer addon board (KiCad 5.0.1, 2019-01-05).
`outputAC.zip` is the order package and contains the same 9 files as `output/`.

The board was designed as `sensor_board-ac-7 -without-regulator-2`, which was later renamed to `addon-ac-dimmer`.

These files were in the first commit and were removed in "Repository cleanup" (5f950e3). They are restored here so
the production files of the physical boards stay visible.
